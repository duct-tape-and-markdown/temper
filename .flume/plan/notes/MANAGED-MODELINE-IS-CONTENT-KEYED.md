# Managed modeline is content-keyed

Shipped as written. One behavioural consequence plan should know: the old
`project_modeline` doc promised a modeline "a human pointed elsewhere" is kept
verbatim. Content-keying ends that: install now re-points any
`yaml-language-server` modeline in a managed frontmatter artifact (CDN face
and represented face alike) to the desired ref. That is what "every managed
line is content-keyed" entails, but no spec line names an opt-out for a
hand-pointed schema; if adopters need one, it is a spec question, not a build
one.
