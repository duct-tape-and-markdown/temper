# Does the bundled reference carry emit's managed-projection note?

Driver: the BUNDLE-EMBEDS-THE-HARNESS-REFERENCE ship note. `src/bundled_reference/` holds emit's output byte for byte, so the plugin's `SKILL.md` and every `kind-*.md` say "edit the owning .temper/ module ... re-run temper emit". In an installed plugin there is no such program, so the note is false guidance to every plugin adopter.

0093 asks for "the same value". (a) Byte equality keeps the note, which is what ships now. (b) The value is the content, so the bundle strips the managed note, which then needs a defined strip seam. A ruling amends `specs/distribution.md`, "What ships — three channels", or 0093.
