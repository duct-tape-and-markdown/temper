# Skills that name their docs as backticked filenames draw `supporting-doc.degree`

From the same real-harness probe (0.0.25). Apart from the load-fault cascade, 37 `supporting-doc.degree` findings come from 7 skills that name their supporting docs as backticked filenames in prose (`` `x.md` ``) rather than markdown links. Agents follow those names, but temper counts no edge. This is a question for plan to raise. Edges are declared, never mined (`contract.md`, "edge"). Is a code span whose text is exactly a sibling document's filename a reference syntax the format carries, like a markdown link, or is it mining? If it is a syntax, the degree counts it. If not, the shipped advisory's guidance should say how to link, so the finding teaches. Note that 2bdb60c3 (a mention renders the target's relative path) gives a represented harness the typed way.
