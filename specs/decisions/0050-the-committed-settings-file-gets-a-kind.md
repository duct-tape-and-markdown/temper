# 0050 — the committed settings file gets a kind

- **Date:** 2026-09-08 · **Status:** accepted · **Amended:** 2026-09-22

## Context

The `(committed-settings-kind)` fork. 0036 typed `settings.local.json` and
ruled nothing on the committed `settings.json`, which three registration
kinds share as collection addresses and no kind governs whole. The first
adopter hit two faces (GH #40): the harness's residue (`autoMemoryEnabled`,
`permissions`) folds in untyped, and the guard can be switched off through
the file it protects — `emit` fingerprints only a manifest with a container
member, so a rewritten `PreToolUse` command passes the boundary and the
next `check`. Ruled by John 09-08; re-ruled 09-22 on finding 0.0.18 ships
co-ownership (the guard admits a residue hand edit, `emit` splices around).

## Decision

**The claude-code face ships `settings`**: the committed
`.claude/settings.json` whole, a JSON document member at the committed
class, singleton identity from its documented path — documented keys
typed, residue opaque and named, **container** of the three registration
collection addresses (their kinds and rows unchanged). The file is a
projection like any other (invariant 7): every key is authored in the
program's `settings` value, the file renders whole from the member, and
its rollup row's byte fingerprint makes any hand edit, a hook command
included, `config_stale`. Claude Code's own writes do not contest it: a
standing permission approval lands in `settings.local.json`, a `/config`
choice in the user or local file; the one write to the committed file is a
project-scope plugin install or uninstall (`enabledPlugins`), which surfaces
as drift routed to the `installed-plugin` member, loud rather than
clobbered (code.claude.com/docs/en/settings, en/discover-plugins, retrieved
2026-09-22).

## Rejected

- **Co-ownership, the 0.0.18 posture**: residue free to hand-edit, the
  fingerprint over temper's segment only — the part-authored file
  invariant 7 forbids, and every hand-added key outlives emit unjudged.
- **A synthetic rollup row under a non-kind label**: a phantom kind the
  corpus, coverage, and admissibility must each be taught to ignore.
- **A bytes digest at the guard alone, or lock rows carrying hook
  commands**: the first misses the next `check`; the second makes the
  projection the database (0018).
- **A collection address for `env`**: an entry has no identity or reach;
  `env` is a documented key, a typed field of `settings`.

## Consequences

`builtins.md` gains `settings` outside the domain partition. Plan derives:
the kind and its documented-profile clauses; `build.container` set so the
rollup row lands; emit rendering the file whole; the guard's residue
allowance retiring; `install` hoisting existing residue into the program;
`unmodeled-surface` retiring for checked segments; a changelog upgrade
note for the reversal. The `(committed-settings-kind)` record deletes.
